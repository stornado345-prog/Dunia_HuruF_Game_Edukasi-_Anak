
# 🎮 Android Edukasi Game Anak

Belajar sambil bermain, tumbuh sambil berkreasi! 🌈

**Android Edukasi Game Anak** adalah aplikasi game edukasi yang dirancang untuk membantu anak-anak belajar dengan cara yang menyenangkan dan interaktif. Aplikasi ini dikembangkan menggunakan Flutter dan Dart untuk perangkat Android.

## 📱 Tentang Aplikasi

Aplikasi ini bertujuan membantu anak mengenal dasar-dasar pembelajaran melalui permainan yang menarik, warna-warni, dan mudah digunakan.

### ✨ Fitur Utama

- 🔤 **Belajar Huruf ABC** — Mengenal huruf A sampai Z.
- 🔢 **Belajar Berhitung** — Mengenal angka melalui aktivitas sederhana.
- 🐻 **Mengenal Hewan** — Belajar nama dan mengenali gambar hewan.
- ⭐ **Kumpulkan Bintang** — Mendapatkan bintang sebagai bentuk penghargaan saat bermain.
- 🔊 **Audio Pembelajaran** — Membantu anak mengenali pengucapan huruf dan kata.
- 🎨 **Antarmuka Ramah Anak** — Desain berwarna-warni dengan navigasi sederhana.

## 🛠️ Teknologi yang Digunakan

- **Flutter** — Framework pengembangan aplikasi.
- **Dart** — Bahasa pemrograman.
- **Android** — Platform target aplikasi.

## 🚀 Cara Menjalankan Project

### Persyaratan

Pastikan perangkat pengembangan kamu sudah memiliki:

- Flutter SDK
- Dart SDK
- Android Studio atau Visual Studio Code
- Android SDK atau emulator Android

### Instalasi

1. Clone repository ini:

   ```bash
   git clone https://github.com/USERNAME/game-edukasi-anak.git
   ```

2. Masuk ke folder project:

   ```bash
   cd game-edukasi-anak
   ```

3. Unduh dependency:

   ```bash
   flutter pub get
   ```

4. Jalankan aplikasi:

   ```bash
   flutter run
   ```

> Ganti `USERNAME` dengan username GitHub kamu dan sesuaikan nama repository jika berbeda.
